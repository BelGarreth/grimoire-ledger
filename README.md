# Grimoire Ledger

A single-file D&D 3.5 character sheet, gear ledger and spellbook. Everything is one `index.html`,
so you can open it in any modern browser.

Live at https://belgarreth.github.io/grimoire-ledger/

## Persistence

State autosaves to the browser's `localStorage`. It survives reloads but stays in that one
browser on that one device, so export a backup if you care about it.

## Run your own copy

1. Fork this repo.
2. **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.
3. A minute later it's live at `https://<your-username>.github.io/grimoire-ledger/`.
